🚀 Personal Portfolio

​Welcome to my personal portfolio! This is a modern, mobile-friendly website designed to highlight my engineering skills, display my project work, and host my resume. It serves as a central hub for recruiters to learn more about my background and connect with me.

✨ Features

🌑 Dark minimal design with purple & teal accents

🖱️ Custom cursor with hover expand effect

🎞️ Smooth scroll-triggered reveal animations

📱 Fully responsive — works on mobile, tablet & desktop

🧭 Fixed navigation with active section highlight

🗂️ Project cards with tech stack & GitHub links

🏅 Certifications section

📬 Contact form with mailto integration
